# Sicurezza

La versione supportata è l'ultima sul branch `main`. La release iniziale è destinata a una LAN fidata e a un singolo processo Node.

Segnala vulnerabilità usando [GitHub private vulnerability reporting](https://github.com/K4pp8/fuori-contesto/security/advisories/new). Non pubblicare token, database o dimostrazioni che espongano partite altrui nelle issue. Se il canale privato non è disponibile, usa i contatti del profilo GitHub del maintainer.

Includi versione, scenario, passi minimi di riproduzione e impatto. Non promettiamo tempi di risposta specifici. Non testare installazioni altrui senza autorizzazione.

Le mani sono private rispetto agli altri client; il gestore del server e chi legge il database possono accedere allo stato. I token locali sono credenziali: non condividerli. Usa HTTPS per connessioni fuori da reti fidate. La policy di retention delle stanze non garantisce cancellazione forense da SQLite, backup o dispositivi.
